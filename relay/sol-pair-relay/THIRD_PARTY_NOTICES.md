# Third-party notices

Sol Pair Relay is independently written inside `codex-relay`. Its package
structure and workflow contracts adapt selected ideas from the MIT-licensed
Poor Relay package and the upstream projects already credited by Poor Relay.
No complete upstream prompt library, persona catalog, command system, or runner
is bundled.

## Poor Relay

- Source: `../poor-relay/`
- Copyright: Copyright (c) 2026 Poor Relay contributors
- License: MIT
- Adapted ideas: exact `tm_*` dispatch, bounded evidence packets, a temporary
  plan artifact, explicit ownership, deterministic checks, protected user
  authority, safe install targets, and static package validation.
- Material change: Sol Pair Relay reduces the child set to three profiles,
  raises all child reasoning to Max, separates planning and execution into two
  fresh Sol contexts, and makes the executor responsible for technical acceptance.
